# Portfolio Demo Video Script

## Opening

Hello everyone, this is my capstone portfolio project built using the Bootstrap framework. The site is a responsive multi-page portfolio designed to highlight my front-end design and development skills while following accessibility and validation best practices.

## Page walkthrough

On the home page, I introduce myself, explain the purpose of the portfolio, and include a contact form with validation feedback. The layout changes between mobile, tablet, and large-screen views to show responsive design decisions rather than a simple scaled-down layout.

On the projects page, I demonstrate one of my extras: a JavaScript filter that lets users sort project cards by category. The page also updates a live text summary for accessibility.

On the gallery page, I meet the image requirement with four local images. I also included a manual carousel with autoplay disabled and modal previews for each image.

## Accessibility and extras

Across the site I used semantic landmarks, a skip link, descriptive alt text, visible focus states, and support for reduced-motion preferences. My four main extras are theme switching with persistence, project filtering, form validation, and motion-aware reveal effects.

## Closing

Thank you for reviewing my portfolio. This project helped me combine HTML, CSS, JavaScript, responsive design, accessibility, and framework-based development in one final site.
