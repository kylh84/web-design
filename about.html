About This Project

This website was created as a CSS and HTML practice assignment. It includes three pages, accessible navigation, a skip link, grid and flexbox layouts, hover effects, box model styling, and the nth-child selector.

Every page contains at least one image, and the gallery page includes more than five images. All images use full URLs from free online sources.

The layout is designed to be simple, readable, and visually balanced.
