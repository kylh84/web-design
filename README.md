# Capstone Portfolio

Responsive multi-page portfolio built with Bootstrap 5 for the "Demo your portfolio (designed using a framework)" capstone.

## Pages

- `index.html`: about, capstone goals, and contact form
- `projects.html`: filterable project gallery
- `gallery.html`: image gallery, manual carousel, and modal previews

## Capstone checklist

- Uses a framework: Bootstrap 5
- At least 3 pages: yes
- At least 2 semantic tags per page: yes
- Responsive for mobile, tablet, and large screen: yes
- At least 4 images on one page: yes, `gallery.html`
- Styled with custom CSS: yes
- Includes 4 extras:
  - Theme toggle with persistence
  - Filterable projects with live status
  - Contact form validation with ARIA live region
  - Scroll reveal with `prefers-reduced-motion` support
  - Bonus: manual carousel and modal image previews

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server.

## Deployment

This folder can be uploaded to GitHub Pages, Netlify, or any static hosting service.
